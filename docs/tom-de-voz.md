# UAIdea — Tom de voz e copy

Derivado das peças institucionais aprovadas. Toda copy do site deve passar por este filtro.

## Os quatro atributos

**Direta.** Frases curtas, afirmativas. O ponto vem antes da justificativa.
**Diagnóstica.** Nomeia o problema do cliente com precisão antes de oferecer solução.
**Estratégica.** Fala de negócio, não de entregável. Post, arte e campanha são meio.
**Próxima, sem ser informal demais.** Trata o leitor por "você", fala como consultor, não como vendedor de rede social.

Voz: primeira pessoa do plural ("criamos", "planejamos", "para nós"). Leitor: sempre "você" / "sua empresa".

## Estrutura padrão de argumento

Toda seção longa segue o mesmo arco já validado:

1. **Gancho** — pergunta ou afirmação que interrompe (`AGÊNCIA NÃO GERA RESULTADO?`)
2. **Diagnóstico** — nomear a dor (`O PROBLEMA NÃO É O SEU NEGÓCIO.`)
3. **Sintomas** — lista curta, sem marcadores, paralelismo rígido (`sem posicionamento / sem identidade / sem objetivo / sem consistência`)
4. **Solução** — o que a UAIdea faz, em frases de uma linha
5. **Elevação** — tirar a conversa do tático (`PARA NÓS, UM POST NUNCA É O OBJETIVO FINAL.`)
6. **CTA** — pergunta que força escolha (`continuar apenas publicando... ou crescer de forma estratégica?`)

## Regras de escrita

- **Títulos:** caixa alta, no máximo 3 linhas, sem ponto final exceto quando a frase é uma afirmação fechada. Verbo forte na primeira linha.
- **Destaque:** apenas **negrito**, dentro do parágrafo. Nunca outra cor, nunca itálico, nunca sublinhado.
- **Listas:** paralelismo obrigatório — mesma classe gramatical, mesmo tamanho aproximado. Máximo 4 itens.
- **Parágrafo:** 2–3 linhas. Se passar disso, quebre.
- **Números:** sempre concretos ou ausentes. Nunca "centenas de clientes satisfeitos".
- **CTA:** verbo no infinitivo ou imperativo + benefício. `Falar com a gente` > `Saiba mais`.

## Vocabulário

**Usar:** estratégia · posicionamento · consistência · autoridade · resultado · propósito · planejamento · os clientes certos · o momento da sua empresa

**Evitar:**

| Não escrever                                                            | Motivo                                               |
| ----------------------------------------------------------------------- | ---------------------------------------------------- |
| "soluções inovadoras", "revolucionar"                                   | vazio, todo concorrente usa                          |
| "parceiro de sucesso", "jornada"                                        | clichê de agência                                    |
| "engajamento" como objetivo final                                       | contraria a tese da marca                            |
| "somos apaixonados por..."                                              | não diz nada ao decisor                              |
| "com certeza", "sem dúvidas"                                            | promessa não verificável                             |
| anglicismo desnecessário (_insights_, _deliver_, _awareness_)           | público não é do meio                                |
| inglês como decoração (`DATA`, `TRACKING`, `PERFORMANCE` em caixa alta) | parece sofisticado para o meio, opaco para o cliente |
| emoji em copy de site                                                   | não faz parte do sistema                             |

### Inglês: quando pode

Nome próprio de plataforma ou tecnologia é permitido, porque não tem tradução: Google Ads, Meta Ads, Next.js, WhatsApp.

Palavra em inglês que **tem** equivalente em português não é permitida como termo de marca. `PERFORMANCE` vira **resultado**; `DATA` vira **dados**; `TRACKING` vira **medição**; `INSIGHTS` vira **leitura** ou **conclusão**.

Teste: se o dono de uma loja de materiais de construção precisar parar para traduzir, reescreva.

## Referência viva: copy já publicada na v2 (`src/content/home.ts`)

Os exemplos acima são didáticos. Os abaixo já passaram pelo filtro e estão no ar — use-os como calibre em vez de inventar um novo par ❌/✅ a cada revisão:

- **Gancho + diagnóstico (herói):** "Marketing para quem mede o **resultado**, não o alcance." — verbo forte, contraste direto, sem anglicismo.
- **Sintomas, paralelismo rígido (posicionamento, coluna "o jeito comum"):** "Entrega tarefa e mede entrega. / Criativo bonito, oferta indefinida. / Relatório de alcance no fim do mês. / Site feito por um, tráfego por outro. / Tecnologia terceirizada, dados perdidos." — mesma classe gramatical, mesmo tamanho aproximado, sem marcador.
- **Elevação (diferencial):** "Um post nunca é o objetivo final. É meio, e às vezes nem isso." — tira a conversa do tático, reforça a tese da marca.
- **CTA que força escolha (seção de contato):** "Seu problema não é falta de post." seguido de "Falar com a UAIdea →" — pergunta/afirmação de gancho, benefício explícito, verbo no infinitivo no botão.
- **Número ausente tratado com honestidade (cases):** `stats` inteiro em `[ — ]` até existir dado real e autorizado — nunca "+100 clientes atendidos" de enchimento.

Ao escrever copy nova, teste contra este bloco antes de testar contra a lista de exemplos hipotéticos: se o tom destoar do que já está publicado, o problema geralmente está na copy nova, não na referência.
